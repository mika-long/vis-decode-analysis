TLDR — Task 3 and Task 5 are both project_to_axis tasks

  • Task 3 is about median identification on a CDF
  • Task 5 is about selecting answers from past answers and ask participants to project to both x-axis and y-axis

For both these tasks, we fitted the data using Gaussian models.

Read in data and scales:

task5_df <- task_df %>%

As can be seen, there are two participants, who have va.resp.x - va.ans.x > 0.4. Let’s also plot what the actual selected answers in data space is:

Code 
task5_df %>%

  ggplot() +
  geom_point(aes(x = data.resp.x, y = data.resp.y, color = "resp")) +

Recall that we are dealing with data that is already cleaned, so why are we still seeing data that is slightly shifted towards the right, for answers on the X-axis? Turns out these two participants were aligning things wrongly on the slider (i.e, they did not match the blue dot to the red dot but matched the thing on the slider to the red dot), hence the shift in their answers. Thus, we exclude these two participants from our analysis for task 5:

task5.x.exclude <- c("667433338e6cc9e53c828774", "67e2f5ebbe69a58c40a5d550")

Math model:

\[ \begin{align} \texttt{error}_i &\sim \mathcal{N}(\mu_{\text{PID}[i]}, \sigma_{i, \text{PID}[i]}) \\ \mu_j &\sim \mathcal{N}(\overline{\mu}, \overline{\sigma}^2)\\ \log(\sigma_{i, j}) &= \alpha_j + \log(\texttt{va.ans.y}_i) \\ \alpha_j &\sim N(\mu_\alpha, \sigma_\alpha) \\ \mu_\alpha, \bar{\mu} &\sim N(0, 1) \\ \sigma_\alpha, \bar{\sigma} &\sim \mathcal{N}^+(0, 1) \end{align} \]

Specify formula and prior:

f <- bf(
  error_va ~ 1 + (1 | participantId),
  sigma ~ 1 + (1 | participantId) + offset(log(va.ans.y))
)

p <- c(
  prior(normal(0, 1), class = Intercept),
  prior(normal(0, 1), class = sd, group = participantId, lb = 0),
  prior(normal(0, 1), class = Intercept, dpar = "sigma"),
  prior(normal(0, 1), class = sd, group = participantId, dpar = "sigma", lb = 0)
)

Fit model:

m.5.x.va <- task5_df %>%
  mutate(error_va = va.resp.x - va.ans.x) %>%
  # exclude the two participants who answered this task wrong
  filter(!participantId %in% task5.x.exclude) %>%
  brm(
    formula = f,
    data = .,
    family = gaussian(),
    prior = p,
    chains = 4,
    cores = 4,
    control = list(adapt_delta = 0.99),
    iter = 6000,
    file = here("analysis", "fitted_models", "task5.x"),
    file_refit = "on_change",
    save_pars = save_pars(all = TRUE)
  )

Task 3 — Find where y == 0.5

Get task 3 specific data:

Code 
task3_df <- task_df %>%
  filter(task == "task3") %>%
  select(-slider.x, -slider.y) %>%
  right_join(participants, by = join_by(participantId)) %>%
  mutate(
    data.ans.y = 0.5,
    data.ans.x = qsgt(
      0.5,
      param.mu,
      param.sigma,
      param.lambda,
      param.p,
      param.q,
      mean.cent = FALSE
    )
  ) %>%
  # do all the calculations for the actual answer
  mutate(
    va.resp.x = exp1_x$data_to_va(data.select.x, dist_to_screen, pixelToMM),
    va.resp.y = exp1_y$data_to_va(data.select.y, dist_to_screen, pixelToMM),
    va.ans.x = exp1_x$data_to_va(data.ans.x, dist_to_screen, pixelToMM),
    va.ans.y = exp1_y$data_to_va(data.ans.y, dist_to_screen, pixelToMM)
  )
