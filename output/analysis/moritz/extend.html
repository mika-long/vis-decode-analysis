Replicating Mortiz et al. Exp 2

Here are the details of the original experiment:

  • Hypothesis: “the effect of variability will be smaller for graphs with points spaced along the x-axis than graphs with points spaced along the arc” (Moritz et al., 2023, p. 5) (pdf)
  • Experiment Design:
    • Within Subject:
      • 2 variability: 0 and 0.4
      • 2 flipped1: upper and lower
    • Between Subject:
      • 3 mark type: line, cartesian spaced points, arc spaced points
        • Note that we will only use cartesian spaced points and arc spaced points for replication.
    • 12 different seeds for randomization -> 2 * 2 * 12 = 48 trials per participant.

1 i.e., whether the plot was flipped or not, where flip == FALSE implies that upper-y region has more variability, and flip == TRUE implies that the lower-y region has more variability

# return visual angle in degrees and not radian
vis_angle <- function(size, distance) {
  return(2 * atan(size / (2 * distance)) * 180 / pi)
}

# define function for turning vis angle to phy size
phys_size <- function(va, distance) {
  return(2 * distance * tan(va * pi / 360))
}

NoteA note on translating between spaces

The goal is to translate from the pixel space to the physical space, and then to the visual angle space.

  1. Data to Pixel: This should be given by the custom VegaEmbed component we built (directly fetching)
  • In this case, data is from \(x \in [0, 120]\) and \(y \in [0, 1]\) with the x-axis mapping to 500 px and y-axis to 200 px.
  1. Pixel to Physical: need to know the pixel to MM ratio, which is different per Participant.
  2. Physical to Vis Angle: need to know the distance to screen, again, which is different per Participant.

Read in fitted model for project_to_y_axis

Recall the we defined the following model for the “project from dot to axis” operator:

\[ \begin{align*} \texttt{error}_i &\sim \mathcal{N}(\beta_0 + u_{\text{PID[i]}}, \sigma_{i, \text{PID}[i]}) \\ \log(\sigma_{i, j}) &= \alpha_j + \log(\texttt{va.ans.x}_i) \\ \text{or:} \log(\sigma_{i, j}) &\sim \mathcal{N}(\mu_\alpha + \log(\texttt{va.ans.x}_i), \sigma_\alpha)\\ \alpha_j &\sim N(\mu_\alpha, \sigma_\alpha) \\ \mu_\alpha &\sim N(0, 1) \\ \sigma_\alpha &\sim \mathcal{N}^+(0, 1) \end{align*} \]

Here is the specification we used for fitting:

# Recall that we defined error = resp - ans
f <- bf(
  error_va ~ (1 | participantId),
  sigma ~ (1 | participantId) + offset(log(va.ans.x))
)

p <- c(
  prior(normal(0, 1), class = Intercept),
  prior(normal(0, 1), class = sd, group = participantId, lb = 0),
  prior(normal(0, 1), class = Intercept, dpar = "sigma"),
  prior(normal(0, 1), class = sd, group = participantId, dpar = sigma, lb = 0)
)

Generate predictions for an “average” participant with fixed pixelToMM and distToScreen

We will make the predictions for an average participant, conditioning on specific values of pixelToMM and distToScreen.

Strategy 1 — Project to vertical line x==0

For a baseline strategy, we assume that the participant projects from the dot to the y-axis, and then performs some mental averaging.

First, we calculate the visual angle values for all the stimuli. This is the route from num -> px -> MM -> VA. This will allow us to make predictions of error in the visual angle space.

# assume that the value of pixelToMM and distToScreen is fixed
# we get the new_data to be crossed with posterior draws

pixelToMM <- 5.12
distToScreen <- 473

# 5760 rows = 2 (plot type) * 2 (noise type) * 2 (flipped or not) *
#  12 repeated measures * 60 points per graph
new_data <- stimuli_df %>%
  # calculate pixel values from numerical values
  mutate(px.x = 500 / 120 * num.x, px.y = 200 * num.y) %>%
  # calcuate physical values (in MM) from pixel values
  mutate(phy.x = px.x / pixelToMM, phy.y = px.y / pixelToMM) %>%
  # calculate visual angle
  mutate(
    va.ans.x = vis_angle(phy.x, distToScreen),
    va.ans.y = vis_angle(phy.y, distToScreen)
  )

Get (thinned) posterior draws:

# 3000 iterations per chain * 4 chains = 12,000 rows
# if we thin by k, then we get 12,000 / k rows
draws <- model %>%
  spread_draws(b_Intercept, b_sigma_Intercept) %>%
  as_draws_df(.) %>%
  thin_draws(thin = 2) # if too much we can also do thinning

Then we go the prediction route: VA -> mm -> px -> num:

pred <- draws %>%
  # every draw * every dot;
  # will result in 5760 * 3000 (thinned version) row
  expand_grid(new_data) %>%
  mutate(
    # mu = b_Intercept,
    sigma = exp(b_sigma_Intercept + log(va.ans.x)),
    # va.pred.error = rnorm(n(), mean = mu, sd = sigma),
    va.pred.error = rnorm(n(), mean = b_Intercept, sd = sigma),
    va.pred.y = va.pred.error + va.ans.y
  ) %>%
  # turn vis angle back to numerical values
  mutate(
    phy.pred.y = phys_size(va.pred.y, distToScreen),
    px.pred.y = phy.pred.y * pixelToMM,
    num.pred.y = px.pred.y / 200
  )

Now we “average”3 across the 60 dots for each trial:

3 Averaging Strategy vs. Median Strategy: “Equal number of points or line below and above. A strategy we did not anticipate was ensuring an equal number of points or line lengths above and below the judgment indicator. To indicate their responses, participants drug a line on the graph. By allowing participants to place a line directly on the graphs, participants could then easily count the number of points above and below the line. One participant simply wrote, “I tried to have the number of points above and below the line be approximately equal.” Unsurprisingly, this strategy was most common for participants who viewed graphs with points equally spaced along the x-axis (24%).” (Moritz et al., 2023, p. 7) (pdf)

avg_pred <- pred %>%
  group_by(ogIndex, expIndex, type, flip, noise, .draw) %>%
  summarise(
    # suppose participants can calculate mean
    num.pred.avg.y = mean(num.pred.y),
    # suppor participants use the median instead
    num.pred.median.y = median(num.pred.y),
  )
NoteHow many rows?

To calculate how many rows that pred has we need to look at these two other dataframes:

  • The draws dataframe has 3000 iterations / chain \(\times\) 4 chains \(\div k = 2\) = 6000 rows
  • The new_data dataframe has 96 trials \(\times\) 60 dots per trial = 5760 rows
  • Therefore pred is going to be 6000 \(\times\) 5760 = 34560000 rows

If we don’t consider rejection sampling, and just calculate the average across all 60 dots for each trial, we will have 34560000/60 = 576000 rows for avg_pred.

Strategy 2 — Project to vertical line where xintercept == 60 and then xintercept == 0

Instead of trying to sum over the results projected to the y-axis, we could have a result projecting to the middle point, i.e., where everyone projects to \(x = 60\), and then use that as an input to then project to the y-axis in order to potentially introduce more variance into the results.

Again, assume that we have fixed values for pixelToMM and distToScreen:

pixelToMM <- 5.12
distToScreen <- 473

# physical distance between vertical line with xintercept == 60 and xintercept == 0
phy.x_ref <- (500 / 120 * 60) / pixelToMM

# 5760 rows = 2 (plot type) * 2 (noise type) * 2 (flipped or not) *
# 12 repeated measures * 60 points per graph
new_data <- stimuli_df %>%
  # calculate pixel values from numerical values
  mutate(px.x = 500 / 120 * abs(60 - num.x), px.y = 200 * num.y) %>% # <- OR NEW (?)
  # calcuate physical values (in MM) from pixel values
  mutate(phy.x = px.x / pixelToMM, phy.y = px.y / pixelToMM) %>%
  # calculate visual angle
  mutate(
    # va.ans.x = vis_angle(abs(phy.x - phy.x_ref), distToScreen), # <- NEW STUFF
    va.ans.x = vis_angle(phy.x, distToScreen),
    va.ans.y = vis_angle(phy.y, distToScreen)
  )

# project to the middle axis
pred <- draws %>%
  # every draw * every dot;
  # will result in 5760 * 3000 (thinned version) row
  expand_grid(new_data) %>%
  mutate(
    # mu = b_Intercept,
    sigma = exp(b_sigma_Intercept + log(va.ans.x)),

    va.pred.y = va.pred.error + va.ans.y
  ) %>%
  group_by(ogIndex, expIndex, type, flip, noise, .draw) %>%
  summarise(
    # assume participants use the mean for second projection
    va.mid_pred.y.avg = mean(va.pred.y),
    # assume participants use the median for second projection
    va.mid_pred.y.median = median(va.pred.y),
    .groups = "drop_last"
  )

# project from middle to the left axis
pred2 <- pred %>%
  left_join(draws) %>%
  mutate(
    # distance to y-axis is vis angle distance from x == 60
    sigma = exp(b_sigma_Intercept + log(vis_angle(phy.x_ref, distToScreen))),
    va.pred.error = rnorm(n(), mean = b_Intercept, sd = sigma),
    va.pred.y.avg = va.pred.error + va.mid_pred.y.avg,
    va.pred.y.median = va.pred.error + va.mid_pred.y.median
  ) %>%
  # turn vis angle back to numerical values
  mutate(
    phy.pred.y.avg = phys_size(va.pred.y.avg, distToScreen),
    phy.pred.y.median = phys_size(va.pred.y.median, distToScreen),
    px.pred.y.avg = phy.pred.y.avg * pixelToMM,
    px.pred.y.median = phy.pred.y.median * pixelToMM,
    num.pred.y.avg = px.pred.y.avg / 200,
    num.pred.y.median = px.pred.y.median / 200
  )
