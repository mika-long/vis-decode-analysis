TLDR

The goal of this file is to (1) recreate the analysis that Moritz et al. produced for their second experiment, and (2) perform a different kind of error analysis, as well as analyze particpant’s whose strategies are closely mapped to the mental averaging and median strategy.

Define helper function for plotting:

Code 
plot_results <- function(data, xvar) {
  data %>%
    ggplot(aes(
      y = variability,
      x = {{ xvar }},
      dist = "norm",
      arg1 = {{ xvar }},
      arg2 = se,
      fill = mark
    )) + #uncertainty
    stat_dist_halfeye(
      show_interval = TRUE,
      position = position_dodge(width = 0.2),
      .width = 0.95,
      size = .5,
      alpha = .8
    ) +
    theme(legend.position = "top") +
    scale_fill_manual(values = c("#76B7B2", "#E15759")) + # take out "#59A14F"
    ylab("Variability") + #add x label
    xlab("Normalized Error") #add y label
}

Analyze signed error

We will calculate error ourselves using reported average and the og stimuli.json:

exp2 <- raw_exp2 %>%
  select(assignmentid, reportedaverage, stimuliindex)

ans_df <- stimuli_df %>%
  filter(type != "line") %>%
  rename(stimuliindex = index) %>%
  unnest(data) %>%
  group_by(stimuliindex, seed, noise, flip, type) %>%
  summarise(mean.y = mean(y), median.y = median(y))

error_df <- exp2 %>%
  left_join(ans_df) %>%
  mutate(
    error_mean = reportedaverage - mean.y, # in the original file, mean.y \equiv data_average
    error_median = reportedaverage - median.y
  ) %>%
  rename(variability = noise, mark = type) %>%
  mutate(variability = factor(variability, levels = c("c(0, 0)", "c(0, 0.4)")))

It seems to me that there are several things that are unexplained in the original analysis:

  • When the original plot is flipped (when flip == TRUE), there seems to be a bigger bias compared to the case when it’s not flipped.
  • When calculating error using the true mean, instead of the mean for the plot with the same seed, we don’t see the same trend that more variability implies bigger error.

Investigate why reversed

So the question becomes: does actual_mean systematically differ from seed_mean in a way that correlates with mark type and variability? (I think the short intuitive answer is yes but need to show proof).

This is where they share averages: same seed, same flip => same average.

raw_exp2 %>%
  select(stimuliindex, seed, mark, flip, variability, data_average, average) %>%
  group_by(seed, mark, flip, variability, average) %>% # data_average,
  summarise(.)

Let us calculate the difference between data_average and average:

raw_exp2 %>%
  distinct(
    stimuliindex,
    seed,
    mark,
    flip,
    variability,
    data_average,
    average
  ) %>%
  mutate(diff = data_average - average) %>%
  ggplot(aes(x = diff, fill = flip)) +
  stat_dotsinterval(alpha = 0.5) +
  facet_wrap(~ mark + variability)

So if we try to account for this and perform a “bias-correction” of some kind:

raw_exp2 %>%
  filter(mark == "point_arc", flip == FALSE) %>%
  distinct(
    stimuliindex,
    seed,
    # mark,
    flip,
    variability,
    data_average,
    average
  ) %>%
  mutate(diff = data_average - average) %>%
  group_by(variability) %>%
  median_qi(diff)

So lets remove 0.0178 and 0.0825 out from it:

exp2 <- raw_exp2 %>%
  select(assignmentid, mark, flip, variability, error, normalized_error)

p_og_corrected <- exp2 %>%
  summarySEwithin(
    data = .,
    measurevar = "normalized_error",
    withinvars = "variability",
    betweenvars = "mark",
    idvar = "assignmentid"
  ) %>%
  mutate(
    normalized_error = case_when(
      mark == "point_arc" & variability == "0,0" ~ normalized_error -
        0.0178,
      mark == "point_arc" & variability == "0,0.4" ~ normalized_error -
        0.0825,
      TRUE ~ normalized_error
    )
  ) %>%
  plot_results(., normalized_error) +
  labs(x = "Bias corrected normalized error") +
  geom_vline(xintercept = 0, linetype = "dashed")

What does the error pattern look like for people who use MEAN strategy?

First we use the lenient way, that is, as long as one rater classifis this as mean, then this counts as mean:

Code 
error_df %>%
  filter(assignmentid %in% lenient_mental_average_id) %>%
  summarySEwithin(
    .,
    measurevar = "error_mean",
    withinvars = c("variability", "flip"),
    betweenvars = "mark",
    idvar = "assignmentid"
  ) %>%
  mutate(
    flip_lab = ifelse(flip == FALSE, "Noise in Upper", "Noise in Lower"),
    flip_lab = factor(flip_lab, levels = c("Noise in Upper", "Noise in Lower"))
  ) %>%
  plot_results(., error_mean) +
  geom_vline(xintercept = 0, linetype = "dashed") +
  facet_wrap(~flip_lab, ncol = 1) +
  labs(x = "True Error", title = "Moritz Exp (Lenient Mean Strategy)") +
  coord_cartesian(xlim = c(-0.04, 0.01))

Then we use the strict way, that is, both rater agree that it’s only mental averaging and not median:
