Perform the correction:

Code 
exp2 %>%
  group_by(assignmentid, mark) %>%
  mutate(subj_mean = mean(normalized_error)) %>%
  ungroup() %>%
  mutate(grand_mean = mean(normalized_error)) %>%
  mutate(corrected = normalized_error - subj_mean + grand_mean) %>%
  group_by(mark, variability) %>%
  summarise(
    mu = mean(normalized_error),
    se = sd(corrected) / sqrt(n()) * sqrt(2 / (2 - 1)), # k is 2 when the within-subj variability is this
    .groups = "drop"
  )

If we do it the same way by calling functions in Functions.R this is what we get:

Recalculate error

It is unclear to me how error is calculated in the original dataset.

exp2 <- rbind(exp2_dotArc, exp2_dotX) %>%
  as_tibble(.)

# normalized error is just error but flipped when flip is TRUE
# the following confirms it.
exp2 %>% count(mark, flip, error == normalized_error)
# and error is just reportedaverage - average
# confirmed by the following
exp2 %>%
  mutate(
    error.1 = reportedaverage - data_average,
    error.2 = reportedaverage - average,
    error.3 = reportedaverage - average_along_arc,
  ) %>%
  select(seed, error.1, error.2, error.3, error, normalized_error) %>%
  arrange(seed) %>%
  filter(!near(error.2, error)) # using dplyr::near becasue of floating point related stuff ....

The above shows up how different things could be if you use different “means” to calculate error … Nothing changes for point because it’s being calculated the right way, but for point_arc … the variability trend basically reverses …

What is consistent, is that when the “variability” region is in the lower region, the error somehow increases … which makes you wonder whether this could potentially be due to dragging …? Or something else …?

We can also plot the version that does not count the flip factor, and just plot the normalized error calculated the original way, vs error calculated compared to the true mean:

Code 
freq_summary <- exp2 %>%
  mutate(
    true_error = reportedaverage - data_average,
    normalized_true_error = ifelse(flip == TRUE, -true_error, true_error)
  ) %>%
  group_by(assignmentid, mark) %>%
  mutate(subj_mean = mean(normalized_true_error)) %>%
  ungroup() %>%
  mutate(grand_mean = mean(normalized_true_error)) %>%
  mutate(corrected = normalized_true_error - subj_mean + grand_mean) %>%
  group_by(mark, variability) %>% # not grouping by flip anymore
  summarise(
    mu = mean(normalized_true_error),
    se = sd(corrected) / sqrt(n()) * sqrt(2 / (2 - 1)), # <- NEW: k is 2
    .groups = "drop"
  )

Read in data related to strategy

Question to answer: people who claim to use mean strategy vs people who claim to use median strategy. Is there a difference between their answers?

strategy_df <- read.csv(here("data", "moritz", "exp", "strategies.csv")) %>%
  as_tibble(.) %>%
  # keep only those related to experiment 2, and only related to point and point arc condition
  filter(Exp == 2, Condition %in% c("point", "point_arc")) %>%
  select(1:4, contains("mental_averaging"), contains("number_of_points"))
