Reanalyze Mortiz

TLDR

The goal of this file is to (1) recreate the analysis that Moritz et al. produced for their second experiment, and (2) perform a different kind of error analysis, as well as analyze particpant’s whose strategies are closely mapped to the mental averaging and median strategy.

Reading in data from Exp 2 (excluding the line condition):

#Exp 2
#point arc
exp2_dotArc <- read.csv(
  here("data", "moritz", "exp", "exp2-point-arc.csv"),
  ,
  check.names = FALSE
)
#point
exp2_dotX <- read.csv(
  here("data", "moritz", "exp", "exp2-point.csv"),
  check.names = FALSE
)
# Combining conditions in Exp 2
exp2 <- rbind(exp2_dotArc, exp2_dotX) %>% as_tibble(.)

Read in the stimuli and calculate the answer for each index * seed

Code 
exp_json_data <- jsonlite::fromJSON(here(
  "data",
  "moritz",
  "stimuli",
  "exp2-stimuli.json"
)) %>%
  as_tibble(.)

stimuli_df <- exp_json_data %>%
  select(index, seed, noise, flip, type, data) %>%
  mutate(noise = as.character(noise)) %>%
  filter(type != "line") %>%
  unnest(col = data)

ans_df <- stimuli_df %>%
  group_by(index, seed, noise, flip, type) %>%
  summarise(ans.mean.y = mean(y), ans.median.y = median(y))
ans_df

Note that the plots produced in the paper, specifically, Figure 2, it was really a summary statistics plot. So we first try to replicate the original correction:

Code 
# when mark == "point", you get average == data_average
# which makes sense, because for `point_arc`, the data average is NOT the actual average ...

exp2 %>%
  mutate(
    error = round(error, 5),
    normalized_error = round(normalized_error, 5)

  # verified that this is how normalized error is calculated
  mutate(
    calc_error = ifelse(
      flip == FALSE,
      reportedaverage - average,
      average - reportedaverage

  filter(calc_error != normalized_error)

exp2 %>%

  mutate(subj_mean = mean(normalized_error)) %>%
  ungroup() %>%
  mutate(grand_mean = mean(normalized_error)) %>%
  mutate(corrected = normalized_error - subj_mean + grand_mean) %>%
  group_by(mark, variability) %>%
  summarise(
    mu = mean(normalized_error),
    se = sd(corrected) / sqrt(n()) * sqrt(2 / (2 - 1)), # k is 2
    .groups = "drop"
  )
